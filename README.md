# SOC-1
* OBJECTIVE-Monitoring and Detection of alerts generated from Authentication logs
* TOOLING-Using SIEM tool known as Splunk Enterprise working on the events generated, detecting true or false positive and conducting further investigation.
* DELIVERABLES-Creation of reports on findings and securing the overall effected accounts and by using MITTRE ATTACK FRAMEWORK mapping the techniques used to help secure the information and the compromised accounts.

## SPLUNK PROCESSING LANGUAGE (SPL)
### QUERIES USED
* Failed login attempt by user 
  index=* action="login" status="failure"

* Failed login count by user, source_ip, location, reason of failure.
  index=* action-"login" status="failure" | stats count as Failed_Attempt by user, src_ip, geo_country, failure_reason, | sort - failed_Attempts
